# بصيرة (Baseera) — منصة تحليل أداء الطلاب

<div dir="rtl">

**بصيرة** منصة ذكاء اصطناعي لتحليل أداء الطلاب، تحوّل بيانات الدرجات إلى رؤى قابلة للتنفيذ — مقدَّمة من **LearnaTech**.

## الميزات الرئيسية

- 🎓 **لوحة المعلم** — نظرة شاملة على الفصل، قائمة الطلاب، الإنذار المبكر
- 👨‍👩‍👧 **لوحة ولي الأمر** — ملخص واضح وعملي لأداء الطالب
- ⚠️ **الإنذار المبكر** — رصد الطلاب في خطر مع أسباب محددة
- 📝 **إدخال الدرجات** — تسجيل النتائج سؤالاً بسؤال وفق المهارة
- 🤖 **الاختبار العلاجي** — أسئلة مولّدة بالذكاء الاصطناعي لكل فجوة مهارية
- 📊 **التقرير الدوري** — تقرير جاهز للطباعة

## التشغيل

افتح ملف `index.html` مباشرةً في المتصفح — لا يحتاج خادماً أو تثبيتاً.

## التقنيات

- HTML5 + CSS3 + JavaScript (Vanilla)
- Chart.js للرسوم البيانية
- Google Fonts: Noto Kufi Arabic + IBM Plex Sans Arabic
